## Why it happens

Windows treats two clicks as a double-click when they come close together in time and in the same spot. It doesn't know whether you meant the second click. If your finger shakes as you press, the button can go down twice in a fraction of a second, and Windows sees a perfectly normal double-click.

So there are three ways to tackle it: make Windows stricter about what counts as a double-click, need double-clicks less often, and make mistakes easy to undo.

## 1. Set the double-click speed for your hand

The double-click speed decides how close together two clicks must be to count as a double-click. It works in both directions, and which way helps depends on your problem:

- **If files open when you only meant to select them,** move the slider towards **Fast**. Two clicks then have to be very close together to count, so some accidental second clicks no longer turn into a double-click. The cost is that a deliberate double-click needs to be quicker too.
- **If you struggle to double-click on purpose,** move it towards **Slow**, as our [mouse guide](/mouse-hand-tremor) suggests. You get more time for the second click.

To change it:

1. Open **Settings** (press the **Windows key and I**).
2. Go to **Bluetooth & devices** > **Mouse**.
3. Under **Related settings**, select **Additional mouse settings**.
4. On the **Buttons** tab, move the **Double-click speed** slider, then select **OK**.

The same tab has a small folder you can double-click to test the setting before you save it.

If you find that no setting suits you, the next section matters more: when you rarely double-click, the speed setting matters less.

## 2. Open things without double-clicking

The fewer double-clicks you need, the fewer can go wrong. Some easy swaps:

- **Select, then press Enter.** Click a file or folder once, then press **Enter** to open it. Or use the arrow keys to move between files and **Enter** to open.
- **Right-click, then choose Open.** A right-click shows a menu with **Open** at the top. Menu items need only a single click.
- **Pin your favourite apps.** Apps pinned to the taskbar or Start menu open with one click.

You may read about a File Explorer option called **Single-click to open an item**. It makes every single click open things. For most people with a tremor that makes accidental opening more likely, not less, so it's usually best to leave Windows on the normal **Double-click to open an item**.

## 3. Make mistakes easy to undo

Even with the best settings, a stray click will sometimes get through. A few keys put things right quickly:

- **Ctrl and Z** undoes the last action in most apps, and in File Explorer it can undo an accidental move, copy or rename.
- **Alt and F4** closes the window that just opened by mistake.
- **Esc** closes most menus and dialog boxes without doing anything.

If you use [Sticky keys](/windows-11-accessibility-tremor), you can press these one key at a time.

## 4. Check that it's not the mouse

Mouse buttons wear out. A worn button can register two clicks from a single careful press, even for someone with a perfectly steady hand. If you get double-clicks when you press slowly and carefully, try a different mouse. If the problem disappears, it was the hardware.

The type of mouse can matter too. Many people with tremor find that a mouse with firmer buttons, or a trackball where the hand can rest while clicking, gives fewer accidental presses. What suits you is personal, so try one before you buy if you can.

## Frequently asked questions

**Why does my mouse double-click when I only click once?**
Either your finger pressed the button twice very quickly, which is common with tremor, or the button is worn. Test with careful, slow clicks: if it still double-clicks, try another mouse.

**Which double-click speed should I choose?**
Towards **Fast** if things open by accident, towards **Slow** if deliberate double-clicks are hard. Use the test folder on the **Buttons** tab to try both.

**Can Windows ignore accidental mouse clicks?**
Not on its own. Windows can filter repeated key presses on the keyboard, but not mouse clicks. Software made for tremor can.

**I opened the wrong file. Did I break anything?**
Opening a file doesn't change it. Close it with **Alt and F4**. If you moved something by accident, **Ctrl and Z** in File Explorer usually puts it back.

## A note on your health

These tips are about making the computer easier to use; they aren't medical advice. If your tremor is new, getting worse or affecting daily life, talk to your doctor.
